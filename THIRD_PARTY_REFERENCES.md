# Third-party references

The Git repository intentionally excludes third-party manuals, papers and
binary distributions. They remain available in the local project tree and are
listed here so a new workstation can restore them without treating them as
project-authored source.

## Required software documentation

- OpenFOAM Foundation 14 User Guide: <https://doc.cfd.direct/openfoam/user-guide-v14/>
- OpenFOAM Foundation 14 Ubuntu package: <https://openfoam.org/download/14-ubuntu/>
- Gmsh 4.15 documentation: <https://gmsh.info/doc/texinfo/gmsh.html>
- PyFoam documentation and upstream project: <https://openfoamwiki.net/index.php/Contrib/PyFoam>
